# Breast Cancer Advanced Analysis

Проект для анализа датасета Breast Cancer (рак груди) с поиском лучшего признака для простой классификации.

## Цель
Найти признак, который лучше всего разделяет доброкачественные и злокачественные опухоли с помощью простого правила `if`.

## Данные
Встроенный датасет из `sklearn.datasets.load_breast_cancer`.

## Запуск
```bash
python breast_cancer_advanced.py
